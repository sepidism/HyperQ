# Project Title

HyperQuery: Beyond Binary Link Prediction

## Running the Code

To run the code, use the following command:


$ python main.py --dataset [dataset]


# Required Packages

Ensure that the following packages (and their dependencies) are installed:

torch == 1.9
numpy == 1.18
scipy == 1.8
sklearn == 0.21.3

pip install -r requirements.txt
